Hey everyone, welcome to Zplit!

Zplit is a new-age decentralized payment‑splitting app being developed by AOSSIE and StabilityNexus.

View Project Docs Join the Design Call

Why Zplit?

Zplit keeps things modern, minimal, and intuitive. The app focuses on decentralized groups, simple expense logging, and insightful graphs — all with a clean, sleek experience.

Decentralized by Design

No central server dependency for core operations; groups live peer‑to‑peer.

Simple Expense Logging

Fast, intuitive flows to add expenses and split fairly across members.

Clear Visual Insights

Graphs and summaries that make tracking spending effortless and transparent.

We’re Inviting Designers to Join the Project

We’re opening a call for designers — this will be the starting point for the app’s visual identity. Submit designs aligned with the minimal, clean, and sleek vibe.

  • Open participation — multi‑assigned issue, anyone can contribute
  • All submissions will be evaluated
  • The best design becomes Zplit’s first theme

Deadline: 1st December 2025

Design Guidelines

1. Theme‑Based UI

Zplit will support multiple themes with potentially different layouts. Keep this flexibility in mind.

2. First Theme

Modern. Minimalistic. Clean. Sleek.

3. UX First

Intuitive flows and easy navigation are top priority.

4. Layout Variants

Submit: Portrait Light/Dark and Landscape Light/Dark versions.

5. Creative Freedom

Ideate new screens, suggest features, and take inspiration thoughtfully.

Required Screens

Onboarding

A set of intro screens showcasing Zplit’s features.

Account Setup (Login/Signup)

Local account; simple inputs (username, name, profile picture).

Groups Page

Create groups and list existing groups.

Invite Users

Invite through methods described in Zplit.md.

Add Expenses

Simple, intuitive interface for logging expenses.

Graphs

Visualizations for expenditure tracking and insights.
