Zplit Website

Overview
- Static marketing and deeplink host for Zplit.
- Minimal, clean, sleek styling with green hues.

Local Preview (npm)
- Ensure Node.js and npm are installed.
- In the repo root, run:

  1) `npm install`
  2) `npm run dev`

- Open `http://localhost:5173/` in your browser.

Notes
- Android asset links are at `/.well-known/assetlinks.json`.
- Replace placeholders with your real `package_name` and `sha256_cert_fingerprints`.
